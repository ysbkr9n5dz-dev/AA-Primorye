# Данные сайта

Всё, что меняется на сайте без программиста, лежит здесь. Код сайта эти файлы только читает.

| Файл | Что внутри |
|---|---|
| `schedule.json` | Города, группы, адреса и собрания (день, время, формат, ссылка, примечание), дата сверки |
| `online.json` | Онлайн-группы без своего адреса (aa24.online, «Ветер Перемен»): платформа, ссылка, доступ, время в своём поясе (`MSK` или `VL`) |
| `news.json` | Новости и события (дата события попадает в календарь и архив) |
| `speakers.json` | Спикерские: аудио, имя, подпись, дата, АА или Ал-Анон |
| `contacts.json` | Телефоны доверия, почта, полезные ссылки |
| `selftest.json` | 12 вопросов «Подходит ли вам АА?» с пояснениями |
| `readings.json` | «Ежедневные размышления» по датам `ММ-ДД` |
| `content.js` | **Собирается автоматически** из файлов выше (`python3 tools/build_content.py`). Руками не править |

Правила:
- запись можно скрыть, не удаляя: `"hidden": true` (группы, онлайн-группы, контакты);
- время собраний в `schedule.json` — владивостокское; у онлайн-групп пояс указан в поле `tz`;
- в `online.json` в полях `big` и `when` время в фигурных скобках `{07:00}` пересчитывается во владивостокское.
