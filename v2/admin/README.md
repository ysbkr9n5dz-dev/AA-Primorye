# Админка сайта АА Приморья

Адрес: `<сайт>/admin/`. Вход по логину и паролю. Редакторы правят новости и события, группы, собрания, адреса, города, онлайн-группы, спикерские и контакты. Каждое сохранение сразу видно на сайте.

## Что нужно на сервере (для администратора сервера)

| Что | Значение |
|---|---|
| PHP | 8.0 или новее, расширения `json`, `fileinfo`, `mbstring` |
| База данных | не нужна, всё хранится в файлах |
| HTTPS | обязательно, иначе пароль передаётся открыто |
| Запись для PHP | папки `content/`, `media/`, `admin/private/` |
| Размер загрузки | для mp3 спикерских: `upload_max_filesize = 256M`, `post_max_size = 260M`, в nginx — `client_max_body_size 260m;` |

Рекомендуется закрыть служебную папку и на уровне nginx (файлы там и так не читаются через браузер):

```nginx
location ^~ /admin/private/ { deny all; }
location ~ ^/media/.*\.php$ { deny all; }
```

## Первый запуск

С консолью на сервере:

```bash
php admin/setup.php roman "Роман"      # пароль спросит, не короче 10 символов
php admin/setup.php alexey "Алексей"
```

Без консоли: создайте `admin/private/config.php`:

```php
<?php return ['setup_key' => 'длинная-случайная-строка'];
```

Откройте `<сайт>/admin/setup.php?key=длинная-случайная-строка`, создайте пользователей и **сразу удалите** `setup_key` из файла.

## Где что лежит

| Путь | Что | При обновлении кода |
|---|---|---|
| `content/*.json` | данные сайта (правит админка) | **не перезаписывать** |
| `content/content.js` | собирается админкой автоматически | не перезаписывать |
| `media/` | загруженные фото, mp3, PDF | **не перезаписывать** |
| `admin/private/` | пользователи, журнал, резервные копии, блокировки входа | **не перезаписывать** |
| всё остальное | код сайта и админки | можно обновлять |

## Защита

- Пароли хранятся только в виде хеша (`password_hash`).
- После 5 неудачных попыток вход с этого адреса блокируется на 15 минут.
- Сессия живёт 12 часов, cookie только для HTTPS и только для этого сайта.
- Каждое действие проверяется токеном (защита от подделки запросов).
- Загрузка — только JPG/PNG/WEBP (до 10 МБ), PDF (до 60 МБ), MP3/M4A (до 250 МБ), с проверкой типа файла. Файлы получают новые имена.
- Перед каждым сохранением раздел копируется (хранятся последние 60 копий). Любую версию можно вернуть в «Настройки и история».
- Если двое правят один раздел одновременно, второй получит предупреждение, и чужие правки не затрутся.
